## 概念发布状态

| 状态        | 概念                                                                                           | 公开规则                                                                      |
| ----------- | ---------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| `published` | 秩序蒸发、官僚休克、二次改开、高脆弱态                                                         | 正式概念；进入概念索引、搜索和 sitemap                                        |
| `reviewing` | 三清时代、财政偿债、政治偿债、统治术、危机管理、国家系统升级、低摩擦治理、政治路线、非暴力转型 | 研究概念；可从概念索引和文章关系进入；`noindex`，不进入搜索和 sitemap         |
| `merged`    | 无                                                                                             | 当前没有足够证据将任一概念直接标记为已合并                                    |
| `held`      | 语言通胀、机会通缩                                                                             | 保留内部框架；不进入概念索引、首页、搜索或 sitemap；原 URL 保留并设 `noindex` |

“语言通胀”和“机会通缩”仍保留各自 URL。本轮没有在理论内容尚未成熟时直接建立合并页或重定向。

## 人工阅读顺序

1. **公民秩序主义入门**：`/start` → 核心问题 → 理论缘起 → 理论手册 → 制度设计入口 → 组织手册。
2. **理解中共当前状态**：高脆弱态 → 官僚系统 → 组织信用 → 三清时代 → 二次改开 → 统治术。

人工顺序缺失文章时会自动跳过，不阻断页面生成；未进入人工顺序的普通文章按同一一级栏目的发布时间顺序提供前后导航。

## 首页调整后的顺序

1. 品牌定位与主要入口
2. 从哪里开始（唯一新读者顺序）
3. 官僚、社会、国家三方诉求
4. 四个核心专题
5. 方法差异入口
6. 四个一级栏目
7. 最新文章（唯一自动更新文章组）
8. 正式资料与联系

## 自动规则

- 最新文章只读取 `published` 且非 `needsReview` 的文章。
- 日期统一使用 `YYYY-MM-DD`；按日期倒序，同日按标题稳定排序。
- 概念关系优先级：显式代表文章 → 原迁移关系 → Frontmatter → 专题关系 → 标签和关键词推断。
- 每篇文章最多显示 3 个概念；研究概念使用虚线和“研究概念”标识。
- 概念页代表文章按 `representativeArticles` 配置顺序优先显示。
- “继续阅读”不包含当前文章、草稿、归档、待复核文章或人工顺序的相邻文章。

## 仍需长期人工判断

- “语言通胀”与“机会通缩”是否最终合并，需要新的完整理论文本，不在本轮自动决定。
- 9 个研究概念何时转为正式概念，需要依据概念边界、机制解释和代表文章成熟度逐项复核。
- `needsReview` 的 14 篇文章分类未在本轮改变。
