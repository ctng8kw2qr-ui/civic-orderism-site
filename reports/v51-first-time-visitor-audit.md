## 1. Executive Summary

V5.1 之后的首页**已经能够承担第一次访问者的主要入口**：陌生读者在首屏就能看到「中国政治转轨的和平方案 / 不革命、不清算 / 保留国家，改变政治」，无需滚动即看到「为什么是现在」；读完 WHY NOW 的两句重点句（「明天会比今天更好。」「明天到底会怎样？」）后，紧接着就是「政治转轨怎么展开？」——「这是什么 → 为什么是现在 → 你们准备怎么办」这条链路在 30 秒内可以完整形成。首页不再被董事会筹备打断：CURRENT WORK 只剩一句话和两个链接，位于价值目标之后，叙事由「怎么改变」自然过渡到「为什么值得改变」。

新人入口同样成立：`/start-here/` 五问完整回答了「是什么 / 为什么现在 / 转轨指什么 / 怎么实现 / 最终要什么」，Q03 明确写出「不是简单的政权崩溃，也不是街头革命」「政治权力发生变化的同时，国家和社会继续运行」，Q04 直接复用五条已确定原则，且第一问在三种宽度下都落在首屏内。

仍有两类明确缺口。第一类是页面完整性缺陷：`/start-here/` 正文结束后只剩一个**空的「本栏目全部文章」标题**（46px、0 条目，全站只有这一页如此）。第二类是身份说明缺口：首页没有任何一句「尚未依法成立」的状态声明，「北美非营利法人及首届董事会筹备」可能被读成组织已经存在；`/start-here/` 也完全不回答项目当前处在什么阶段。此外，首页在两处正文段落末尾各放了一个跳转全文的链接，恰好落在阅读节奏的交接点上。

结论：方向与层级已经正确，剩余问题集中在**身份边界说明**与**页面收尾完整性**，不涉及信息架构重做。

## 2. 30-Second Test（首页）

**总时长对应内容**：Desktop/Tablet 首屏 = HERO 全部 + WHY NOW 标题；第二至三屏 = WHY NOW 正文 + TRANSITION 标题与五步链条。

### Q1. 这是什么？ — **4 / 5**

读者能准确理解为「为中国未来和平政治转轨做准备的政治路线项目」。

- **首次建立认识的位置**：首屏第一行品牌与标题（`CIVIC ORDERISM · 公民秩序主义` → `中国政治转轨的和平方案`），紧接着 `不革命、不清算，在保持国家连续运行的前提下，为中国未来建立一条低阻力、低风险的政治转轨路径。`（Desktop y=417、Mobile y=228，均无需滚动）。
- **是否存在歧义**：存在一处。首页从头到尾**没有一句说明「谁在说这些话」**（没有「我们是一个……」的自我定义句）。读者能读出「这是一个方案」，但读不出说话主体的性质，只能从 `CURRENT PHASE · 当前阶段：和平政治转轨路线建设与组织筹备 / 2026` 推断这是「一个正在筹备的项目」。
- **误认风险**：一般政治评论网站 低（页面结构制度化、无信息流）；媒体 低（无新闻、无更新列表）；海外抗议组织 低（首屏即写「不革命、不清算」）；**智库 / 研究机构 中低**（栏目化、有正式 PDF、有研究页，但页面自称「政治路线」）；**未来政党 中低**（出现「北美非营利法人及首届董事会筹备」，容易被理解为组织已在运作）。

### Q2. 为什么是现在？ — **5 / 5**

完全达到预期判断，且是本次审计中表现最好的一段。

- **是否太抽象**：不抽象。具体到「收入会增加 / 生意还能扩大 / 机会还会更多 / 官员的生活和未来有稳定预期」。
- **是否太长**：Desktop 804px、Mobile 906px（约 1.1 屏），8 段共约 300 字；但两个视觉重点句（左侧强调线、字号更大）承担了扫读功能，30 秒内只读这两行加结尾两句也能得到完整判断。判定合格。
- **是否太像理论文章**：不像。无术语、无引注、无定义句。
- **与 HERO 衔接**：自然。HERO 给出方案与原则，WHY NOW 立刻回答「为什么需要」，两者共用同一套词汇（政治转轨 / 国家连续运行）。
- **是否推动继续阅读**：是。结尾「政治转轨不是未来某一天才需要面对的问题。它已经成为今天必须开始准备的问题。」正好把问题抛给下一段标题「政治转轨怎么展开？」。

### Q3. 它和一般「反对中共」的政治项目有什么不同？ — **4 / 5**

- **能自然发现的差异（首页实际文字）**：
  - 不革命：首屏「不革命、不清算……低阻力、低风险的政治转轨路径」（首屏可见）
  - 不清算：同上，且 `/start-here/` 五原则明确「不以群体性政治报复作为新政治秩序的起点」
  - 不以国家失序作为政治机会：TRANSITION 说明「不等待旧体系自己完成改革，也不依靠社会失控推动政治变化」
  - 强调过程：TRANSITION 链条 01→05 本身就是过程模型
  - 强调国家连续运行：链条第 04 步「保持国家连续运行」，HERO 也已出现
  - 降低旧体系参与者阻止转轨的动力：链条第 03 步「降低官僚系统阻止转轨的动力」
  - 重点是准备替代路线而非表达反对：BUILDING 四项（政治路线 / 政治信誉 / 组织能力 / 国家承接准备）与 CURRENT WORK 承担这一层
- **扣分原因**：只有「不革命、不清算」在 30 秒内可直接看到；「不以国家失序作为政治机会」「不是表达反对，而是准备替代路线」这两条**从未被写成对比句**（首页没有出现「与反对运动不同」「不同于抗议」之类的说明），读者必须自己从链条第三步和建设四项中推断。也就是说差异存在，但**最具有区分度的两条要读到第三屏才能拼出来**。
- 结论：不存在需要读很久才能发现的问题，但存在「需要推断而不是被告知」的问题。

### Q4. 它准备怎么做？ — **4 / 5**

读者能形成要求的简单认知：不是等崩溃后再想办法，而是提前准备路线、信誉、组织与承接能力，让变化尽量和平发生并保持国家连续运行。

- **顺序自然**：01 旧体系无法自行改革（起点判断）→ 02 外部政治承接力量提前形成（前置条件）→ 03 降低官僚系统阻止转轨的动力（降低阻力）→ 04 保持国家连续运行（底线）→ 05 逐步完成政治换轨（结果）。功能各不相同，无逻辑跳跃。
- **是否有重复**：链条本身无重复，但第 04 步「保持国家连续运行」与 HERO 说明句、TRANSITION 小结句、BUILDING 第 04 项形成四次同义重复（见 §9 P2-4）。
- **是否出现只有内部读者才理解的术语**：轻微。「外部政治承接力量」「降低官僚系统阻止转轨的动力」属于需要停顿一下的表述；「官僚系统」是日常词，「政治换轨」是比喻。对中文母语读者不构成障碍，但都不是「零门槛词」。扣 1 分。

### Q5. 最后想要什么？ — **4 / 5**

- 段落内容（第 4 屏，Desktop y=2238 起，Mobile y=2264 起）：标题「这一次，让中国成为你的骄傲」→ 问题「中国，什么时候能让生活在这里的人，因为自己的生活而感到骄傲？」→ 判断「一个国家真正的荣耀，不只出现在新闻报道里，更应该写在每一个普通人的生活里。」
- **是否过于抽象**：偏抽象但仍可理解。读者能说出：目标是让普通人的生活值得骄傲，而不是政权更替本身。
- **是否过于政治化**：不过度。没有出现敌我语言、没有口号化排比。
- **是否有人和生活的感觉**：有，「生活在这里的人」「普通人的生活」是具体的人；但首页没有给出任何**生活层面的具体结果**（例如教育、医疗、就业、安全感等），因此「为什么值得做」只能靠共情回答。
- **是否能够回答「为什么值得做这件事」**：能回答方向（值得生活、值得期待），不能回答具体内容。扣 1 分。
- 补充观察：30 秒读者通常尚未滚动到这里（位于第 4 屏），因此这一节对 30 秒测试的贡献有限；它主要服务于 60 秒以上的读者。

**30-Second Test 总分：4 + 5 + 4 + 4 + 4 = 21 / 25**

## 3. Five-Minute Test（/start-here/）

**入口独立前提**：本项按「从搜索引擎直接进入 `/start-here/`」评估（不依赖首页）。

### 1. 公民秩序主义是什么？ — **5 / 5**

Q01 给出完整回答：不是政治评论项目、不是内容平台；是一条面向中国未来政治转轨的政治路线；理论研究提供判断基础，组织建设建立现实承接能力；要回答的不是哪种制度最理想，而是如何在降低冲突与社会代价的前提下完成下一次政治转型。并附一行主线「政治路线 → 组织承接能力 → 和平政治转轨」。

### 2. 为什么今天提出？ — **5 / 5**

Q02 完整复述核心判断（明天会比今天更好 → 重新计算未来 → 明天到底会怎样），并明确「政治转轨不是未来某一天才需要面对的问题，它已经成为今天必须开始准备的问题」。理论解释被降级为一句指路链接。

### 3. 所谓政治转轨具体指什么？ — **5 / 5**

Q03 直接给出否定与肯定两面：不是简单的政权崩溃，也不是街头革命；不是等旧秩序倒下才开始，也不把国家本身当作革命对象；重点是政治权力发生变化的同时国家和社会继续运行——公共服务不停摆、社会秩序不失控、普通人不必支付无法承受的代价。

### 4. 准备通过什么基本路线实现？ — **4 / 5**

Q04 给出五步主线与五条已确定政治原则（不革命 / 不清算 / 保留国家 / 和平承接 / 提前准备），并指向完整路线。扣 1 分的原因：这一页使用「外部政治承接力量」「组织承接能力」等核心词，但**页内没有任何一句解释「谁在承接、凭什么承接」**；对完全陌生的读者，「承接力量」会停留为一个抽象名词。

### 5. 最终希望中国变成什么样？ — **4 / 5**

Q05 给出「值得生活、也值得期待未来的国家」＋五项方向（有边界的权力 → 有责任的政治 → 有连续性的国家 → 有尊严的公民 → 有纠错能力的制度）＋「保留国家，改变政治」的再解释。扣 1 分原因有两点：

1. 五项方向是**无解释的价值清单**，读者能复述词条，但说不出每一项的具体含义；
2. 这一页最后紧跟一个**空的「本栏目全部文章」标题**（详见 §9 P1-1），新人入口以悬空标题收尾，削弱整页的完成感。

**Five-Minute Test 总分：5 + 5 + 5 + 4 + 4 = 23 / 25**

**独立性结论**：`/start-here/` 可以独立完成「是什么 / 为什么现在 / 转轨含义 / 基本路线 / 最终目标」五项理解，**不需要回看首页**。但它不回答「项目现在处于什么阶段、由谁在做」——从搜索直接进入的读者只能通过 Q05 的按钮「当前组织建设」离开本页才能知道（见 §9 P2-5）。

## 5. Likely Misunderstandings

1. **误认为组织已经存在。** 首页 CURRENT WORK 写「北美非营利法人及首届董事会筹备」，词汇本身包含「筹备」，但首页没有任何一句像 `/about/` 与 `/preparation/` 那样的声明（「北美非营利法人尚未依法成立……首届董事会尚未依法产生」）。第一次访问者只知道这是一个网站，最容易把「法人 + 董事会」理解为「已经有一个机构在运作」。页脚身份行「北美非营利法人及首届董事会筹备中」是唯一的即时提示，位于页面最底部。

2. **误认为这是研究机构 / 智库。** 首页有栏目化的研究区、正式 PDF、以及「解析中共 / 中国未来」这样的研究标签，但**没有一句机构自我说明**（没有「我们是一个……的组织 / 项目由谁发起」）。不预设立场的读者更可能把它归入「研究机构发布的报告网站」，而不是「一条政治路线项目」。

3. **误认为「政治转轨」是有时间表的事件。** 首页反复强调「已经成为今天必须开始准备的问题」，但没有任何一句说明「转轨什么时候、由什么条件触发」。愿意花 30 秒的读者可能读成「项目在预测政权更替时间」，而页面实际主张的是「提前准备承接能力」。这一误解与 P1-2 同源：缺少状态与边界说明。

（其余潜在误解未发现明显证据，故不凑满。）

## 9. Remaining Problems

分级定义：**P0** 严重误导项目身份，必须立即修；**P1** 明显影响第一次访问者理解，应优先修；**P2** 有改善价值，但不阻碍基本理解；**P3** 审美、工程维护或微小体验问题。

### P0

**无。** 审计未发现会让陌生读者对项目性质产生根本性误判的内容（例如被读成政党、竞选、募款或抗议组织）。首屏「不革命、不清算」与全站无募款/无成员名册的结构足以排除最严重的误认。

### P1

**P1-1｜`/start-here/` 结尾出现空的「本栏目全部文章」标题**

- 证据：构建产物 `public/start-here/index.html` 末尾为 `<section class="page-listing" aria-label="本栏目全部文章"><h2>本栏目全部文章</h2><ul class="section-ul"></ul></section>`；实测 `display: block`、高度 46px、`<li>` 数量 0；全站仅此页为空列表（`china-stage` 3 条、`institution` 1 条，其余页面不渲染该模块）。
- 影响：新人入口页的最后一屏是一个没有任何内容的栏目标题，紧跟 Q05 的四个按钮之后。
- 建议方向（不在本轮执行）：让 `/start-here/` 不渲染 folder listing（在页面 frontmatter 或布局条件中关闭），或为该模块补一条实际内容。

**P1-2｜首页没有「组织尚未成立」的即时状态说明**

- 证据：首页 CURRENT WORK 仅出现「北美非营利法人及首届董事会筹备」＋「为政治路线、政治信誉和长期责任建立正式、合法、可持续的组织载体。」；「北美非营利法人尚未依法成立，具体注册法域尚未确定，首届董事会尚未依法产生」只出现在 `/about/` 与 `/preparation/`；首页唯一的「筹备中」提示在页脚 tagline。
- 影响：第一次访问者可能把「法人 + 首届董事会」理解为已有机构在运作，进而高估项目现状。
- 建议方向：在 CURRENT WORK 的一句话定位中并列一句状态边界（例如「法人尚未依法成立，首届董事会尚未依法产生」），不增加段落、不新增 section。

### P2

**P2-3｜两处「离页 CTA」落在阅读节奏的交接点**
TRANSITION 段末「查看完整和平转轨路线 →」与 FUTURE 段末「阅读价值目标全文 →」都位于「怎么改变 → 为什么值得改变」「为什么值得改变 → 需要什么能力」的衔接处，顺着读的读者可能被提前带离首页。

**P2-4｜「国家连续运行」在首页重复四次**
出现位置：HERO 说明句「在保持国家连续运行的前提下」、TRANSITION 链条第 04 步「保持国家连续运行」、TRANSITION 小结句「保持国家继续运行」、BUILDING 第 04 项「保持国家运行」（另在 `/start-here/` 五原则「保留国家」中再次出现）。信息无错，但同一屏层级的同义表达密度偏高。

**P2-5｜`/start-here/` 不回答「项目现在处于什么状态」**
五问结构按 V5.1 取舍移除了「现在正在做什么」，读者只能点「当前组织建设」离开本页。从搜索引擎直接进入者因此无法判断项目规模与阶段（首页 CURRENT WORK 已提供，`/start-here/` 未提供）。

**P2-6｜页脚身份行仍以组织筹备作为站点自我描述**
页脚固定为「北美非营利法人及首届董事会筹备中」，而首页叙事已改为「先政治、后组织」。二者并不矛盾（页脚是状态说明），但对刚读完首页的读者而言，页脚会把注意力拉回组织维度。

**P2-7｜首页 `updated: 2026-09-23` 已写入但当前不可见**
证据：`content/index.md` frontmatter 为 `date: 2026-07-19` / `updated: 2026-09-23`；构建产物中检索 `2026-09-23` 无任何命中；`sitemap.xml` 首页 `<lastmod>` 仍为 `2026-07-19T04:00:00.000Z`（内容索引使用 `defaultDateType: "published"`，见 `quartz.config.ts`）；带 `dateModified` 的 Article JSON-LD 只对文章页输出（首页只有 BreadcrumbList）；首页隐藏 ContentMeta。
影响：字段语义已正确、重跑生成不会回退，但搜索引擎与读者都不会看到本次修订。若要对外生效，需要另一项决定（例如把 `defaultDateType` 改为 `modified`，或为非文章页补 dateModified）——本轮未执行。

### P3

**P3-8｜「浏览全部研究与出版」指向研究枢纽页**
落地 `/theory/` 是「三个研究方向 + 辅助入口 + 当前重点」，全部文章索引其实在 `/articles/all`。文案「全部」略强。

**P3-11｜英文 eyebrow 与折行**
首页五个 eyebrow 全为英文（WHY NOW / THE TRANSITION PATH / WHAT WE ARE BUILDING / CURRENT WORK / RESEARCH & POLITICAL WORK），对纯中文陌生读者信息量低但无害；`CORE POLITICAL STATEMENT · 价值目标` 在 Desktop 左栏会折成两行（既有现象，非本轮引入）。

**P3-12｜身份与状态信息分散在两个二级页**
`/about/` 有 CURRENT STATUS，`/preparation/` 有法律状态说明，但两页之间没有交叉引用提示；读者读到其一未必知道另一个存在。

**P3-13｜返回路径依赖浏览器**
