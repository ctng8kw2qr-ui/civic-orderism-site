# 安全化—清洗—再集中—再失灵模型

<p class="concept-status concept-status--published">正式概念</p>

<p class="concept-definition">安全化推动组织清洗和权力再集中，而再集中又削弱治理反馈并产生新一轮失灵的循环模型。</p>

| 字段 | 内容 |
| --- | --- |
| 更新时间 | 2026-07-20 |
| 知识状态 | 正式概念 |

## 完整解释

这一模型把安全优先、官员清洗、权力集中和治理能力下降视为连续机制，而不是彼此孤立的政策现象。组织用清洗和集中回应不确定性，却可能进一步削弱专业反馈和地方行动，新的失灵又被解释为控制仍然不足。

## 形成机制

安全化触发清洗，清洗推动再集中，再集中压缩反馈与行动能力，失灵由此再次积累。

## 现实表现

- 清洗常态化
- 决策继续上收
- 失灵被再次解释为控制不足
