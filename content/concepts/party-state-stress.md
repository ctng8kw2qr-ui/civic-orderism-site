# 党国应力

<p class="concept-status concept-status--published">正式概念</p>

<p class="concept-definition">党的政治控制逻辑与国家治理逻辑长期重叠后，不断积累的结构性张力。</p>

| 字段     | 内容       |
| -------- | ---------- |
| 更新时间 | 2026-07-20 |
| 知识状态 | 正式概念   |

## 核心判断

党国应力关注党与国家两套不同运行逻辑被置于同一权力系统后形成的长期张力：党要求忠诚、安全和路线统一，国家治理则必须回应财政、人口、公共服务和责任分配等现实约束。增长可以暂时掩盖这种张力，进入损失分配阶段后，控制继续集中与治理能力下降便可能相互强化。

## 形成机制

政治控制持续进入国家治理，权力与责任同步集中，现实问题又反过来推动进一步控制。

## 现实表现

- 党承担无限政治责任
- 行政判断让位于政治安全
- 控制增强而治理效能下降
