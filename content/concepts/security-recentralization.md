# 安全再集中

<p class="concept-status concept-status--published">正式概念</p>

<p class="concept-definition">安全化循环中的关键阶段：安全优先级上升后，权力、信息与责任进一步向中心集中。</p>

| 字段     | 内容       |
| -------- | ---------- |
| 更新时间 | 2026-07-20 |
| 知识状态 | 正式概念   |

## 完整解释

安全再集中是安全化—清洗—再集中—再失灵循环中的关键阶段，而不是与完整循环并列的一级模型。它描述当不确定性被视为主要风险后，组织持续收紧授权、信息与责任边界的过程。它可以提高命令一致性，却也可能压缩地方和专业系统的判断空间，使更多问题回流到中央。

## 形成机制

风险上升推动授权收缩，授权收缩又使责任与决策进一步集中。

## 现实表现

- 地方裁量收缩
- 信息与责任上收
- 发展目标服从安全边界
