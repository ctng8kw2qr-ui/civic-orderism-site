# 核心概念词典

这里汇集全站持续使用的解释模型与政治路线概念。正式概念已经形成稳定定义；研究概念仍在完善边界，但可以作为继续阅读的知识节点。

## 解析中共类

<p>从党国结构、官僚系统、组织信用与安全逻辑理解中共运行方式。</p>

<div class="concept-grid"><a class="concept-card" href="/concepts/order-evaporation"><strong>秩序蒸发</strong><span>制度形式仍然存在，但可信承诺、协作能力和社会预期逐步流失的过程。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/bureaucratic-shock"><strong>官僚系统休克</strong><span>官僚系统在高风险、强问责和低授权环境中出现的集体行动冻结。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/second-reform"><strong>二次改开</strong><span>对中国是否可能再次通过系统性开放与改革重建增长和组织空间的判断框架。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/high-fragility"><strong>高脆弱态</strong><span>系统表面高度集中和稳定，实际对少数节点、资源或决策失误异常敏感的状态。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/party-state-stress"><strong>党国应力</strong><span>党的政治控制逻辑与国家治理逻辑长期重叠后，不断积累的结构性张力。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/security-recentralization"><strong>安全再集中</strong><span>安全优先替代发展优先后，权力、信息与责任不断重新向中心集中的治理过程。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/organizational-credit"><strong>组织信用</strong><span>组织能否持续兑现承诺、分配责任并让成员相信长期合作仍然有意义的能力。</span><small>正式概念</small></a>
<a class="concept-card" href="/concepts/security-purge-recentralization-cycle"><strong>安全化—清洗—再集中—再失灵模型</strong><span>安全化推动组织清洗和权力再集中，而再集中又削弱治理反馈并产生新一轮失灵的循环模型。</span><small>正式概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/three-cleans-era"><strong>三清时代</strong><span>用于观察财政清账、政治清责与组织清洗同步出现的阶段框架。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/fiscal-debt"><strong>财政偿债</strong><span>对长期依赖债务、土地与未来收入形成的财政成本进行集中结算。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/political-debt"><strong>政治偿债</strong><span>过去通过模糊责任、延迟改革或压缩反馈所累积政治成本的集中显现。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/ruling-techniques"><strong>统治术</strong><span>组织为了维持控制而使用的压力传导、信息管理、激励与惩罚工具。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/crisis-management"><strong>危机管理</strong><span>组织在风险中优先维持可控性、责任边界与行动连续性的机制。</span><small>研究概念</small></a></div>

## 公民秩序主义类

<p>从和平转轨、国家连续、低阻力治理与政治路线理解公民秩序主义的方案。</p>

<div class="concept-grid"><a class="concept-card concept-card--research" href="/concepts/state-system-upgrade"><strong>国家系统升级</strong><span>在保留国家连续性的同时重建入口、判断、执行、纠偏与问责系统。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/low-friction-governance"><strong>低摩擦治理</strong><span>通过清晰入口、责任边界与信息系统降低公共问题处理的制度交易成本。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/political-route"><strong>政治路线</strong><span>把价值目标转化为进入现实、组织行动与制度过渡的可执行路径。</span><small>研究概念</small></a>
<a class="concept-card concept-card--research" href="/concepts/nonviolent-transition"><strong>非暴力转型</strong><span>以降低冲突、避免清算并维持国家基本能力为约束的政治转型路径。</span><small>研究概念</small></a></div>
