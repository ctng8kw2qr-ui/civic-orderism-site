# Editorial source masters

Editable SVG/PNG masters for production editorial artwork. The published raster
in the parent directory is rendered from these; edit here, then re-export.

| Master | Production | Article |
|---|---|---|
| `ccp-system-transformation.svg` | `../ccp-system-transformation.webp` | 《中共正在变成什么？》 |
| `editorial-economic-future-horizon.png` | `../editorial-economic-future-horizon.webp` | 《中国经济的未来在哪里？》 |

Render at the canonical cover ratio (1.9:1), master 2400×1263. The
`editorial-economic-future-horizon` artwork is supplied at 5:2 and is published
at that proportion (1600×640 web), with a page-scoped display override.
